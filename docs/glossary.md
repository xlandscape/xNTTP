# Glossary

## Model Terms

- **Component**: A model unit with declared inputs and outputs that performs one stage of the simulation.
- **Landscape Model core**: The framework that configures experiments, executes components, checks data semantics, and
  stores exchanged values.
- **Monte Carlo run**: One execution of the configured model composition within an experiment.
- **Observer**: A service that receives status, warning, and error messages during model execution.
- **Scenario**: A package of spatial and supporting data that describes the simulated landscape.
- **Store**: The data backend used for values exchanged between components.

## Exposure and Effect Terms

- **Application rate**: Amount of product applied per unit field area, expressed in `g/ha` in the standard xNTTP setup.
- **Dose-response model**: A function that translates exposure into a relative biological response using parameters
  such as slope and EC50.
- **EC50**: Exposure level associated with a 50% response in the configured dose-response relationship.
- **Exposure grid**: Spatial and temporal array of pesticide deposition generated by SprayDrift.
- **In-crop buffer**: Untreated distance inside a field boundary.
- **Non-target terrestrial plants (NTTPs)**: Plants outside the intended crop and treatment target that may be exposed
  to a plant-protection product.
- **Spray drift**: Movement and deposition of spray droplets outside the treated area.
- **TerRQ**: Threshold-based effect component used by the optional non-IBC workflow.

## IBCgrass Terms

- **IBCgrass**: Individual-based model of grassland plant-community dynamics used as an xNTTP effect model.
- **Initialisation period**: Simulation period used to establish the community before evaluating treatment effects.
- **Patch centre**: Coordinate at which xNTTP samples the exposure grid for an IBCgrass simulation.
- **Plant functional type (PFT)**: Group of plants represented by a common set of ecological and life-history traits.
- **Random PFT sensitivity**: Treatment of the unknown mapping between regulatory test-species responses and grassland
  PFTs. In the current xNTTP workflow, EC50 and slope are sampled independently from endpoint-specific intervals for
  every PFT and repetition; this is not literal selection of one complete observed test-species curve.
- **Recovery period**: Period after herbicide treatment used to evaluate subsequent community development.
- **Seeds per type**: Annual seed input for each plant functional type, representing immigration into the community.
- **Test species**: Terrestrial non-target plant species measured in an ecotoxicology study and used as a surrogate
  source of dose-response information; it is not automatically equivalent to an IBCgrass PFT.
